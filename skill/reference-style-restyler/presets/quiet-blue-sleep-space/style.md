# 抱抱云朵社「白场蓝色功能岛」视觉规范

## 核心定义

在暖白无边界空间中，以低饱和雾蓝色软体家具建立一个可躺、可坐、可拥抱的生活功能岛。人物、产品与家具共同构成画面主体，岛外保持安静留白，形成柔软、低刺激、有安睡感的商业摄影画面。

## 空间

- 背景与地面采用暖白或浅灰白，并柔和连成无边界白场。
- 空间功能由一组低矮家具及人物的使用方式表达。
- 主功能岛集中在画面中下部，周围保留连续、干净的白色留白。
- 家具之间通过前后遮挡、尺寸差异和软织物垂落建立纵深。
- 画面不建立可识别的墙面、门窗、踢脚线和完整装修系统。

## 功能岛

- 使用一件大型低矮软体家具作为唯一主岛：卧室使用低床，客厅使用圆润沙发或软榻。
- 主家具使用低饱和雾蓝、粉末蓝或浅灰蓝，成为画面的最大有色体块。
- 人物与产品自然进入主家具的使用关系，产品仍是主要传播对象。
- 配置一件面积较小、颜色略深的压舱家具，如中等木色边几、矮柜、灯架或深灰蓝边柜。
- 只保留建立使用关系所必需的家具和软装。

## 前景

- 前景用于建立纵深和引导视线，不固定配置独立家具。
- 卧室优先使用床尾、床品褶皱、垂落织物、浅色地毯边缘或柔和阴影。
- 客厅优先使用沙发近端、贵妃位、扶手、垂落织物或浅色地毯边缘。
- 前景保持克制，与主功能岛连成一个整体，不形成第二个视觉中心。

## 配色

- 背景与地面：暖白、浅灰白，占画面最大面积。
- 主家具：低饱和雾蓝、粉末蓝、浅灰蓝。
- 软装：奶油白、米白、浅灰米色。
- 压舱元素：中等深度木色、灰棕色或深灰蓝，仅占小面积。
- 人物与产品保持自身颜色。
- 整体明亮、柔和、低饱和，蓝色集中在大型家具上。

## 构图

- 采用“上空、下实”的结构，上部约三分之一保留大面积留白。
- 主家具、人物和产品集中在中下部，形成单一明确的视觉中心。
- 前、中、后景通过主家具近端、织物、地毯和小型压舱家具建立。
- 画面保持宽松呼吸感和清晰的产品阅读空间。

## 文案排版

- 文案进入白色留白区域，与功能岛共同构成完整海报。
- 主标题位于上方偏右区域，使用纤细宋体或现代衬线中文，字号较大、行距舒展。
- 情绪引导文案位于左上，小字号、短行、两至三行。
- 补充文案位于左下，品牌或系列信息位于右下。
- 英文使用小字号、大字距，与中文主标题形成轻重对比。
- 文字以柔和蓝灰色为主，保持轻盈、克制和可读。
- 风格迁移时逐字保留原图文案内容，重新设计字号、层级、对齐和位置。

## 光线与材质

- 使用接近大型柔光棚或阴天天光的漫射光，方向感弱、阴影浅而柔软。
- 白色背景保留轻微明暗渐变，家具下方保留自然接触阴影。
- 画面明亮但不刺眼，低对比、低刺激。
- 家具与软装以棉、绒、针织、棉麻等柔软吸光材质为主。
- 家具轮廓低矮、圆润。

## 风格迁移规则

- 锁定输入图中的人物身份、产品结构与颜色、人物和产品的核心互动，以及全部文案内容。
- 以原图中同景深的床、沙发、普通枕头、人物或家具表面为尺度锚点，保持产品相对于参照物的宽高占比、占用面积、接触位置和遮挡关系；机位改变时保持等效真实尺度与透视关系。
- 重新构建背景、家具、机位、景别、主体位置和文案版式。
- 使用最接近目标场景、机位和压舱元素的一至两张内置参考图。
- 最终画面呈现完整的白场蓝色功能岛和真实使用关系。

## 验收要点

1. 背景和地面构成暖白无边界空间。
2. 大型核心家具使用低饱和雾蓝色，并形成唯一主功能岛。
3. 画面中有一件小面积、略深的压舱家具。
4. 前景来自主家具、织物、地毯或阴影，并服务于空间纵深。
5. 主体集中在中下部，上方保留充足留白。
6. 文案采用克制的四角信息系统和蓝灰色纤细字体。
7. 光线柔和漫射，材质柔软可触，整体具有安睡、陪伴和低刺激感。
8. 人物、产品和文案内容保持准确。
9. 产品相对于同景深床、普通枕头或其他稳定参照物保持与原图一致的真实尺寸感；优先使用两个独立参照关系交叉核对。

## 统一生图描述

暖白无边界摄影棚式空间，背景与浅灰白地面自然衔接。用低矮、圆润的雾蓝色床、沙发或软榻建立唯一的生活功能岛，将人物与产品自然安置其中；增加一件面积很小、颜色略深的木质或灰蓝家具稳定画面。前景由主家具近端、垂落织物、浅色地毯边缘或柔和阴影自然形成。主体集中在中下部，上方保留大面积留白，并按四角信息系统排布纤细蓝灰色文案。使用安静的柔和漫射光、浅软阴影以及棉、绒、针织等吸光材质，呈现明亮、低饱和、低刺激的安睡氛围。
